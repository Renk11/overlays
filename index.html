3

Вставь в OBS одним источником

Вся сцена целиком: один источник «Браузер» вместо нескольких. Подходит для Twitch, YouTube и VK Видео.

  1. В OBS в блоке «Источники» нажми «+» и выбери «Браузер».
  2. В поле URL вставь ссылку на сцену. Ширина 1920, высота 1080. Пользовательский CSS не трогай.
  3. Фон прозрачный сам. Поставь источник над игрой и камерой.
  4. Для рамки камеры подгони окно камеры под рамку на предпросмотре. Для рамки чата поставь окно чата внутрь.
  5. Под каждую ситуацию делай свою сцену: игра, общение, «Скоро начнём», перерыв. Готовые сборки есть в списке слоёв.
  6. Анимация появления играется при загрузке источника. Включи в его свойствах «Обновлять браузер, когда сцена становится активной».
  7. Хочешь менять текст без замены ссылки: войди, сохрани сцену и возьми «постоянную ссылку».
  8. Свой логотип игры или фон: положи картинку в репозиторий рядом с сайтом и впиши её имя, например logo.png.
